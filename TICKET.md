# MF-1912 Show a merchant's bank details to support

**Type:** Story · **Team:** Support tools · **Reporter:** Product (Merchant support)

Support agents can see a merchant's payout bank details when they are helping with a payout problem. Bank details are the account number and the routing number. The payout screen also shows the account holder's name.

An agent with an open ticket for that merchant can see them. Team leads can see them for any merchant. Until now, agents without an open ticket have been shown the last four digits of the account. Every view is logged with an audit id.
